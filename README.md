# 小约动画

**由家长选内容，让孩子安心看动画。**

小约动画是一款为儿童和家庭设计的 Android TV 动画播放器。家长可以连接自己的 OpenList、AList 或 NAS，将选定文件夹中的视频整理成动画片库，自主决定孩子观看的内容，并设置每日观看时长。

软件按实际播放时间记录观看历史，提供每日观看日历，以及按动画、片库和标签划分的时长统计。对于英语启蒙家庭，可以按启蒙路线、阶段或主题为动画打标，直观查看每条路线、每部动画的累计观看时长和每天的观看记录。

**管理后台内置于 APK，无需为本应用另行部署服务器。** 在电视端开启管理后，同一局域网内的电脑通过电视显示的 IP 和端口即可维护片库、视频来源、标签与观看规则。OpenList、AList 或 NAS 等外部视频来源仍需自行准备。

## 主要功能

- **自己选片**：接入外部 OpenList / AList、NAS（SMB / WebDAV），按目录扫描整理动画、季和集；支持自动识别与手动维护。
- **适合遥控器**：按片库或标签选片、继续观看、切换剧集；全屏播放时中间键暂停/播放，左右键快退/快进，下键打开选集和设置。
- **每日时长管理**：设置默认额度，家长解锁后可单独调整今日额度；达到上限允许看完当前集，再停止继续播放。
- **观看日历与统计**：按天查看记录，分别统计动画、观看时所属片库和当前标签的实际观看时长；暂停、缓冲和进度跳跃不计入时长。
- **英语启蒙路线标签**：支持 K/V 多值标签，例如 `庆爸路线=常规一`、`庆爸路线=常规二`；可以整部、整季或批量打标，同一集可归属多条路线。
- **本地数据与备份**：片库、标签和观看记录保存在电视端；视频保留在原视频来源，支持资料备份与恢复。
- **电脑管理**：APK 内置局域网管理页面，电脑浏览器登录即可使用，无需额外的应用管理服务器。

## 英语启蒙怎么用

1. 将自行挑选的动画目录加入片库。
2. 按路线或阶段批量打标，例如为一季添加 `庆爸路线=常规一`。
3. 在电视端按标签生成播放列表。
4. 在统计中查看该路线和动画的实际观看积累，在日历中查看每天看了什么、看了多久。

后补标签也会归入已有观看历史。同一集可以属于多个标签，因此各标签行可能重叠；全局总时长始终去重，不能简单相加标签行。

## 当前状态

当前版本 **0.1.6**，处于开发测试阶段。已在 Android TV API 34 ARM64 模拟器完成相关验证，实体电视、盒子和不同视频编码的兼容性仍需实机测试。最新统计修复通过 63 项 Android JVM 测试和 4 项模拟器专项测试，详见[验收记录](docs/validation-0.1.6.md)。

本项目不内置动画资源，不提供网盘账号或第三方资料服务密钥；视频与图片由使用者自行提供并管理。应用源代码使用 [MIT 许可证](LICENSE)，第三方依赖和 Gradle Wrapper 保留各自许可证。

## 构建

需要 JDK 17、Node.js 22 或更新版本、Android SDK Platform 35 及对应构建工具。最低 Android API 配置为 26；实际兼容机型以验收记录为准。将 Android SDK 路径放入未提交的 `local.properties`（`sdk.dir=...`）。

```sh
npm --prefix web-admin ci
npm --prefix web-admin test
npm --prefix web-admin run build
./gradlew :core:test :app:testDebugUnitTest :app:assembleDebug
```

调试 APK 输出：`app/build/outputs/apk/debug/app-debug.apk`。Web 构建产物必须存在后才能打包 APK；开发服务器不能代替 APK 内置管理页。

无 Android SDK 时，领域层也可通过 `mvn -f core/pom.xml test` 独立验证。下载依赖需要访问 npm、Maven、Google Android 和 Gradle 分发站点。

## 首次使用

1. 将调试 APK 安装到测试电视或盒子，使用遥控器进入家长设置。
2. 完成家长答题验证，设置独立的电脑管理员密码并开启局域网管理。
3. 在同一局域网电脑打开电视显示的地址，登录管理页面。默认 HTTP 连接不加密，只适用于可信家庭局域网，不建议映射到公网。
4. 添加外部资源源并选择目录；在资料服务配置中填写自己的 OpenSubtitles/TMDB API key。未配置 key 时仍可扫描和手工维护。
5. 检查扫描匹配结果、确认候选、批量关联季集及打标签，然后在 TV 端选片。

OpenSubtitles 仅用于 `moviehash` 搜索，不下载字幕。片名、季集和图片识别不是百分之百可靠；人工修改需保留字段保护。第三方服务的授权和署名以实际使用条款为准。

## 数据与观看规则

- 同一个 K 可有多个 V；同 K 筛选取并集，不同 K 筛选取交集。
- 标签统计以当前标签追溯历史；多个标签行可重叠，总时长不重复计算。
- 每日首次进入可跳过并使用默认额度；今日额度修改需家长验证，修改总额度不清零已看时间，次日恢复默认。
- 达到额度后只允许看完当前集。家长答题是操作门槛，不能证明答题者身份。
- 电视应用停止、断电或系统休眠可能使管理网页不可达，重新打开应用后恢复。

## 备份与回滚

重装或更换电视前导出备份；源凭据和活动授权不随普通备份恢复，换机后需要重新输入。恢复前保留当前数据快照。数据库升级失败不得自动清空旧库；降级时使用兼容版本备份，不直接打开更高版本数据库。

升级前，在电脑管理页导出备份并保存当前 APK。安装新版时使用覆盖安装，避免卸载应用造成私有数据库被删除：

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

如果启动报告数据库升级失败，先保留安装和数据，不要点系统“清除数据”。应用会保留旧库并显示重试/退出入口；将错误发生前后的 `adb logcat -d` 日志交给维护者。开发调试包可在停止应用后用 `adb shell run-as cn.childtv` 导出数据库目录作诊断，必须同时保留 SQLite 主文件和仍存在的 `-wal`、`-shm` 文件。

需要回退旧版时，在另一台测试设备或独立安装环境中安装兼容 APK，再导入升级前导出的备份。确认片库、历史、标签及额度后重新输入资源凭据。不要为强行安装旧 APK 而先清除唯一的数据副本；旧版不能读取新数据库时，应使用与备份格式兼容的版本恢复。
