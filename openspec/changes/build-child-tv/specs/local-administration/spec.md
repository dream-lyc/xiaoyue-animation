## ADDED Requirements

### Requirement: 应用内局域网管理服务

系统 SHALL 在 TV 应用内提供可启停的管理服务与访问地址，桌面浏览器可登录使用，无需独立部署本应用服务。

#### Scenario: 开启管理
- **WHEN** 家长在电视启用服务并完成初始凭据设置
- **THEN** 同局域网电脑可通过显示的 IP/端口登录

#### Scenario: 系统终止
- **WHEN** 电视休眠或系统终止进程导致服务不可达
- **THEN** 界面及文档明确运行限制，重开应用恢复服务和已保存数据

### Requirement: 管理认证与凭据保护

系统 SHALL 对管理 API 执行认证，使用独立管理员密码和限时会话，提供退出与登录限流，并校验跨站修改请求；TV 算术授权不得代替 Web 登录。

#### Scenario: 匿名访问
- **WHEN** 未登录客户端读取片库或提交修改
- **THEN** 请求被拒绝，不泄露源凭据

#### Scenario: 跨站请求
- **WHEN** 其他网站通过已登录浏览器尝试修改设置
- **THEN** 不符合 Origin/CSRF 校验的请求被拒绝

#### Scenario: 凭据展示
- **WHEN** 浏览器读取已有源配置
- **THEN** 仅返回脱敏状态和允许修改的字段，不返回可复用密码或令牌

### Requirement: 电脑浏览器管理界面

系统 SHALL 提供源/目录、扫描状态、片库、批量标签、候选匹配、日历、统计、观看规则和备份界面，第一版仅适配电脑浏览器。

#### Scenario: 片库维护
- **WHEN** 家长在电脑选择待匹配视频并确认剧集
- **THEN** 修改通过同一领域服务持久化，TV 刷新后显示一致资料

#### Scenario: HTTP 启用说明
- **WHEN** 家长启用默认局域网 HTTP 管理
- **THEN** 界面说明适用于可信局域网且传输未加密，不宣称公网安全

### Requirement: 本地持久化与备份恢复

系统 SHALL 将片库、人工覆盖、标签、历史、进度和策略保存在电视，并提供带版本和完整性校验的备份；视频不复制入备份，敏感凭据及授权会话不明文导出。

#### Scenario: 换机恢复
- **WHEN** 在兼容版本导入有效备份
- **THEN** 恢复稳定 ID、资料、历史和策略，要求重新配置资源凭据

#### Scenario: 备份损坏
- **WHEN** 导入无效或不兼容的备份
- **THEN** 拒绝导入并保留现有数据；有效恢复前保留恢复前快照

#### Scenario: 升级失败
- **WHEN** 数据库 schema 迁移失败
- **THEN** 保留旧库及诊断，不自动重建空数据库
