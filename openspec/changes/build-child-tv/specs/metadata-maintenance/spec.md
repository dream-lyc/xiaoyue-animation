## ADDED Requirements

### Requirement: 分层自动识别

系统 SHALL 自动读取本地 NFO/影视 ID、解析目录和文件名，并在资料服务已配置时调用接口识别动画、季和集；人工锁定字段优先。

#### Scenario: 已有资料
- **WHEN** 目录包含可解析 NFO 和封面
- **THEN** 系统使用其中身份和资料建立候选或匹配，并保留来源

#### Scenario: 服务未配置
- **WHEN** 用户未填写在线服务所需 API key
- **THEN** 系统显示配置缺失，仍完成文件扫描并允许手动维护

### Requirement: 文件指纹辅助查询

系统 SHALL 在文件未确认且服务和范围读取可用时计算 OpenSubtitles moviehash 并调用搜索，不调用字幕下载；将真实 hash 命中与名称回退结果区分。

#### Scenario: 指纹查询
- **WHEN** 文件大小和头尾各 64 KiB 可读取且 API key 有效
- **THEN** 系统发送 moviehash 搜索，保存匹配证据，不请求下载字幕

#### Scenario: 读取不支持
- **WHEN** 源不支持随机读取或文件不适用 hash 算法
- **THEN** 系统记录不可用原因并使用其他匹配方式，不为 hash 强制下载整个视频

#### Scenario: 服务限流
- **WHEN** 资料接口返回 429 或临时故障
- **THEN** 系统遵守限流退避并保留可重试任务，不阻断手动入库

### Requirement: 匹配结果与资料补全

系统 SHALL 区分已匹配、待确认和未匹配；仅唯一且证据一致的候选可自动关联；匹配后查询 TMDB 等资料源补全资料和图片。

#### Scenario: 明确匹配
- **WHEN** 文件季集编号、动画身份和提供方结果一致且唯一
- **THEN** 系统自动关联并获取名称、简介和可用图片

#### Scenario: 冲突候选
- **WHEN** 名称线索与 hash 指向不同剧集或存在多个候选
- **THEN** 系统展示证据与候选供家长确认，不静默选择第一条

#### Scenario: 没有结果
- **WHEN** 所有匹配方式无结果
- **THEN** 系统保留可手动归类的视频和未匹配状态

#### Scenario: 缺少图片
- **WHEN** 动画或剧集没有可用的本地或在线封面
- **THEN** 系统使用对应视频的首帧并缓存，动画可采用旗下剧集的首帧；截取失败使用占位图，不冒充官方封面

#### Scenario: 已有片库缺图
- **WHEN** 浏览已有片库中没有封面的剧集
- **THEN** 系统可自动补取首帧，无需删除重建源；合辑映射使用该集区间起点，人工维护的封面不被覆盖

### Requirement: 人工与批量维护

系统 SHALL 支持手动建立动画/季/集，修改名称、简介、编号和封面，整季关联及批量调整集号；已修改字段受保护。

#### Scenario: 人工修正后重扫
- **WHEN** 家长修改封面或集名后重新扫描
- **THEN** 系统保留人工值，只有显式解除保护或确认覆盖才可替换

#### Scenario: 整季映射
- **WHEN** 家长选择一批文件并指定动画、季及集号规则
- **THEN** 系统展示逐文件映射预览，确认后批量提交

#### Scenario: 多集视频
- **WHEN** 一个文件包含两集且家长指定各集时间区间
- **THEN** 系统将两个逻辑集关联到该文件各自区间并按集播放和统计
