# 小芽影院 0.1.1 测试版

## 本次修复（2026-10-28）

- OpenList/AList 明确区分账号密码与访问令牌。账号密码通过 `/api/auth/login` 换取内存中的 Token，再调用文件接口；旧配置有用户名时按密码模式兼容。源凭据仍保存在 Android Keystore 保护的本地存储。
- 401 时最多重新登录一次，403 不循环登录；密码和源认证头不透传到视频直链。非法令牌格式只返回固定提示，不回显内容。
- 认证、目录、限流及网络错误显示具体类别。源认证失败不再误触发电脑管理会话退出。已选择目录时测试这些目录的权限。
- 家长题改为随机单步口算：20 以内加减法（非负）或 1—9 个位数乘法，不再出两位数乘法或混合运算。授权时效、动作绑定和错误限流不变。

## 验证

48 项核心测试、49 项 Android JVM/Room 测试、41 项 Web 测试全部通过。5 项 Android TV API 34 设备回归通过（19.205 秒），包含实际 Media3 播放与新题型授权。构建和 Lint 通过（0 错误、24 条既有警告）。APK 内电脑资源与最新 dist 逐字节一致，覆盖安装保留原数据，冷启动通过。

已对现有 OpenList 源做一次真实只读连接诊断：返回 AUTHENTICATION/401，不能宣称已连通。后续仅检查本地元信息，确认有效认证方式为 password 且存在用户名，没有重复尝试登录。用户表示尚未核对账号密码，需要先在 OpenList 网页确认，再在小芽后台更新凭据。该结果不单独证明密码错误，也未区分登录阶段与目录阶段的拒绝。

## 安装及继续测试

模拟器已覆盖安装本版。刷新 http://127.0.0.1:8080 并重新登录电脑管理；在资源源的“更新凭据”中选择“账号密码登录”，填写核对后的 OpenList 用户名、密码，再点测试连接。不需要删除重建源。
