# 小芽影院 0.1.6 测试版

## 调整范围

修复 TV 观看统计的分组明细被固定高度的汇总和趋势区域挤压的问题。按动画、按观看时片库、按当前标签使用已有不同分组查询；同一日期范围的全局总时长、去重集数、观看天数和每日趋势保持一致。

分组明细需要在首屏可见，长列表可通过遥控器浏览。已有观看但没有标签时显示对应空状态，不误报没有观看记录。

## 验证

测试使用隔离数据库与人工构造的观看记录，不向用户片库加入样例。设备测试按 TV 实际内容区高度约束布局，并通过遥控键切换维度、浏览长列表。

修复前设备测试 3 项失败：动画首行不可见、12 行分组无法用方向键到达末行、无标签时没有明确空状态。夹具真实 API 返回 2 个动画 / 1 个片库 / 2 个标签分组，证明分组查询已有区分。首次夹具缺少权威 ID 的测试错误已修正，该错误未计作功能复现。

修复采用紧凑合计、左侧主要分组明细和右侧每日趋势。明细项支持焦点与方向键滚动，切换维度或日期范围后回到首行。未修改统计后端、观看记录结构或电脑管理端。

初轮修复后设备 3 项通过（14.279 秒），Android JVM 63 项通过，Lint 0 错误 / 25 条既有警告。

最终回归：4 项模拟器测试全部通过（19.846 秒）；Android JVM 63 项全部通过；Lint 0 错误、25 条既有警告。覆盖真实 API 三维分组、首行可见、真实最后分组的遥控浏览、无标签空态、20 日趋势的末日期浏览。滚动验证在固定方向键操作后等待最多 3 秒完成布局与语义更新，未增加按键数或放宽目标。

每日柱与明细支持完整的可访问描述；图柱使用单行分钟数，完整日期和时长保留在语义描述中。电脑管理端资源逐文件与 dist 相同。
