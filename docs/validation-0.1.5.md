# 小芽影院 0.1.5 测试版

## 调整范围

移除 0.1.4 的实底按钮面板，改为中性黑色透明渐变、文字导航与细线进度。播放/暂停、快进快退直接由遥控器中间与左右键控制，不再提供对应按钮或画面比例设置。

播放时按下键先显示当前列表的上一集、下一集，再按下进入倍速与同集换源设置。列表边界不可选，切集先保存当前观看计时，再沿用开播策略校验。返回键逐层返回，进度浮层不会抢占连续播放/快进快退操作。

## 修复前对照

旧版实际设备测试三项失败：首个下键没有选集层；确认/快进快退后进入完整设置面板而非简洁进度；缺少逐层下翻设置路径。记录位于 .tooling/015-controls-red.log。

## 验证状态

- Android JVM/Room：63 项通过，无失败或跳过；APK 与测试包构建通过。
- Android Lint：0 错误、25 条既有警告。
- APK 中的电脑管理端资源与 web-admin/dist 逐文件一致。
- API 34 ARM64 模拟器专项 10 项全部通过，104.761 秒：全屏、下翻选集/设置与返回层级、相邻集回调与边界、重复切集保护、中间/左右/媒体键连续控制、倍速选择、8 秒自动隐藏、暂停和错误菜单、反复缓冲区域稳定、真实播放计时与每日额度/日历聚合。
- 原生 BACK、PlayerView/表面实例及区域稳定断言通过；LOCKED 后中心键和媒体播放键仍不能重新开播。

## 调试与审查记录

- 播放错误后，画面已切到选集层但无障碍树仍保留旧进度层。将视频焦点接收区域改为浮层的同级节点，保持 PlayerView 和视频表面实例不变；针对错误菜单与返回层级复测通过。
- 首尾集禁用检查最初命中了 Compose 生成的文字描述子节点。实际 XML 显示可点击父节点 enabled=false；测试改为检查最近可点击操作节点，保留禁用断言。
- 审查发现切集解析等待期间重复确认会再次发起导航。新增测试在旧实现复现回调 2 次而非 1 次；加入切集等待保护，阻止重复切集和旧视频恢复播放，并阻止在途换源覆盖切集。
- 上一集、下一集各用独立测试场景验证暂停、最终进度与观看时长先持久化，再导航；手动切集与自动播完回调分开。
- 测试使用隔离数据库和合成视频，不操作用户资源源。
