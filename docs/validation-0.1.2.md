# 小芽影院 0.1.2 测试版

## 修改范围

- 缓冲、连接及播放状态提示叠加到固定视频区域，不再占用视频下方高度。
- 缺少可用封面时尝试视频首帧，保留本地/在线图片优先级与手工封面保护。合辑使用对应集区间起点。
- 旧片库浏览时按需补取缺图并缓存；动画封面可借用旗下剧集图片。读取失败短暂退避，避免连续访问资源源。

## 修复前对照

Android TV API 34 ARM64 模拟器：原播放器缓冲时视频区域从 1920×920 变成 1920×808，布局回归测试失败。修复后连续三轮实际 BUFFERING/READY 切换通过，播放器、视频视图及渲染 Surface 对象保持不变。既有实际播放/暂停计时/每日额度回归同时通过。

首帧夹具为开头红色、随后蓝色的短视频。旧版两项设备测试失败：默认取得第 1 秒的蓝色画面；未匹配剧集未生成缓存。

## 验证状态

核心 48 项、Android JVM/Room 55 项全部通过。后者包含 6 项新增封面集成测试，覆盖旧片库按需回补、合辑起点、动画代表图、手工封面优先及并发保护、失败退避。构建通过，Lint 0 错误、24 条既有警告。

设备首轮 8 项中 7 项通过；Media3 测试原有“8 秒视频应计 7—10 秒”断言失败。独立复跑同样失败，阶段诊断显示媒体 8 秒实际经过 13.619 秒，持久计时 13 秒；暂停期间 2756 ms 累计保持不变。这表明原测试将媒体进度误当实际观看时长。设备测试改为独立观测 isPlaying 单调时间区间并与持久化事件对照（误差不超过 500 ms），生产计时逻辑未修改。

最终完整设备回归 **8 项全部通过**，用时 58.7 秒，包含真实首帧解码、未匹配视频封面、连续缓冲布局、实际计时/暂停/收尾/授权/统计。APK 已覆盖安装并重新打开，后台端口转发恢复为 http://127.0.0.1:8080 。发布 APK 与构建产物一致，内嵌电脑端资源与 dist 逐字节一致。

## 边界

截帧仍受源可用性、范围读取、读取预算及设备解码能力限制，失败保留占位。首帧本身若为黑画面，会按原视频显示。已有可用封面缓存不批量重算。没有执行真实电视兼容性或用户 OpenList 源认证验收。
