# 小芽影院 0.1.4 测试版

## 交互目标

播放画面默认铺满播放器区域，常驻按钮改为底部覆盖面板。上下键呼出设置，打开面板不暂停或缩放视频；面板隐藏时确认键切换播放/暂停，左右键快退/快进 10 秒。返回键先关闭面板，再退出播放。正常播放时闲置 8 秒自动收起，暂停/出错时保留。

面板包含进度与播放状态、倍速、画面比例、同集换源、家长设置、返回片库及出错重试。相关操作沿用现有额度与计时规则。

参考：[Android TV 播放控件指南](https://developer.android.com/training/tv/playback/controls)（2026-10-28 查阅）。

## 修复前对照

新增隔离的 debug 播放测试宿主，只使用合成视频与独立数据库。旧版真实设备测试两项失败：视频区域 1920×920，未铺满 1920×1080 窗口；下键无法呼出设置面板。结果位于 .tooling/014-controls-red.log。
