# 小芽影院 0.1.3 测试版

## 日历观看记录修复

日历此前将每个播放检查点及额度拆分片段直接列为一行，造成同一视频连续出现多条 1 秒或 0 分钟记录。现在双端按播放会话、日期、剧集及观看时归属汇总，同次播放的暂停、缓冲及正常/收尾类型切换不会拆分卡片；退出重播和跨日记录保持独立。

先合计毫秒再换算展示秒数。正时长不足一秒显示“不到1秒”；混合记录列出实际包含的观看类型。原始事件、累计与策略逻辑不变，无数据库迁移。已有版本的 UUID 会话记录直接适用；无法识别会话的历史记录保守保留，仅有确切连续边界的同检查点正常/收尾两半合并。

- Android JVM/Room 63 项全部通过，包括 6 项新增日历聚合测试及 2 项 TV 展示测试。

- Lint 0 错误、24 条既有警告。
- API 34 ARM64 模拟器真实 Media3 回归通过（29.822 秒）：实际计时、暂停不计、额度收尾、授权及统计仍通过；多个正常/收尾事件汇总为一条日历记录，毫秒总计相等。
- 覆盖安装保留现有数据，实际用户日历在 2026-10-28 显示 14:48 那次观看为一条 31 秒记录，当日总计仍为 31 秒。验收截图位于 releases/0.1.3/screenshots/calendar.png。
