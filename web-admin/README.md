# 小约动画 · 桌面家长端

React + TypeScript + Vite 静态应用，随电视 APK 内嵌分发。只使用同源 `/api/v1` 的真实数据，不含生产演示片库。最低桌面宽度 1080px，参考 1440px 暖白/鼠尾草绿原型。

```sh
cd web-admin
npm ci --legacy-peer-deps
npm test
node --test src/transport.node-test.ts
npm run build
```

`dist/` 由 Android 构建任务复制到 APK 的 `admin/` 资源目录。开发服务器仅监听 `127.0.0.1`；需要真实 TV API 的同源代理后才能登录，不提供内置模拟服务。

实现登录/过期/退出、源配置与重输凭据、多目录浏览、扫描状态和取消重试、剧集人工维护与自动字段保护、候选证据确认、连续季集映射、资源多版本与单文件多集播放区间、批量标签预览确认、标签字典、日历每日记录、去重统计、默认观看规则、在线资料凭据及备份恢复。

会话与 CSRF token 仅保存在运行内存，敏感密钥输入保存后清空。HTTP 提示说明仅用于可信家庭局域网。今日额度与额外一集使用 TV 答题流程，桌面只显示今日状态并维护默认额度。

测试通过仅证明客户端行为与约定请求格式，尚未代表实机、真实 NAS/在线提供方、跨设备备份或双端统计已完成验收。按用户要求未使用电脑操作工具，也未进行浏览器截图视觉验收。统计支持任意日期范围，并按片库、动画、当前标签筛选；当前第一版没有独立片库/季实体管理或虚拟大列表分页。

API 约定见 [`../docs/admin-api.md`](../docs/admin-api.md)。
